# Progress Summary

Our project investigates whether smaller-weight CNN student models can approximate Stockfish well enough for edge-device chess analysis. We use compact convolutional networks because chess boards can be encoded like small multi-channel images, and we compare standard CNNs with depthwise separable CNNs because depthwise layers should reduce weights and computation. The student has a shared convolutional backbone plus two heads: a policy head for Stockfish-like move probabilities and a value head for board evaluation. Our dataset comes from the Lichess open database; preprocessing converts PGN games into FEN positions, encodes each board as an 18-channel 8x8 tensor, and labels positions with local Stockfish MultiPV analysis. In our first test, 40 games produced 1,399 positions and 998 usable labels at depth 6 with MultiPV 5, and we trained four small student variants. For the final experiments, we will scale beyond about 1k labels, increase Stockfish depth, train longer, and sweep CNN width/depth for both standard and depthwise models. Expected outputs include Top-1/Top-3 move agreement, value RMSE, value correlation, parameter count, model size, memory use, and CPU latency. We will interpret results with Pareto frontier plots to identify which student models best balance Stockfish imitation accuracy against edge-device cost.
