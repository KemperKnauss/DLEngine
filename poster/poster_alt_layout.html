Distilling Stockfish into a Lightweight Student Model

We are building a smaller-weight CNN student that approximates Stockfish's move choices and board evaluations while staying practical for edge-device CPU inference.

University of Washington · CSE · Spring 2026
Research Question

How small can a Stockfish-style student model be before it loses useful chess judgment?

We focus on the tradeoff between model size and teacher imitation: as the student has fewer weights and faster CPU inference, how much agreement with Stockfish's preferred moves and evaluation scores does it retain?

This matters for edge devices because teacher-quality chess analysis usually depends on expensive search. A compact local model could make basic analysis possible when memory, latency, or power are limited.

Data

Datasets & Preprocessing

Positions will be sampled from the Lichess open database and labeled with a local Stockfish executable. The final experiment will scale this dataset after validating the full pipeline on a smaller sample.

  • PGN to FEN — games are expanded into individual board positions
  • Stockfish MultiPV — top candidate moves and centipawn evaluations become teacher labels
  • Tensor encoding — 18 channels encode pieces, side to move, castling rights, and en passant state

MultiPV centipawn scores are converted into soft policy targets so the student can learn that several moves may be reasonable, while the best evaluation is mapped to a bounded value target.

Methodology

Teacher-Student Pipeline

Stockfish is used as the teacher and a compact CNN is trained as the student. The student has a shared convolutional trunk, a policy head for move probabilities, and a value head for board evaluation.

Student Architecture

The student model is a lightweight convolutional neural network. A CNN works well here because the encoded chess board is shaped like a small multi-channel image: each channel marks one type of board information across the same 8x8 grid.

We compare a standard compact CNN with a depthwise separable CNN. The standard CNN learns spatial patterns and cross-channel piece interactions in one convolution. The depthwise version separates those two jobs, which should reduce weights and computation while still learning useful board patterns.

PartStandard CNNDepthwise CNN
Input 18 board-state channels Same 18 x 8 x 8 tensor
Convolution One 3x3 filter mixes space and channels together Depthwise 3x3 spatial filter per channel
Channel mixing Built into the same convolution Pointwise 1x1 convolution mixes channels
Policy head Predicts move logits Same output, fewer backbone weights
Value head Predicts board evaluation Accuracy-cost comparison

Student Training Loss

ℒ = CE(pSF, pS) + λ · MSE(vS, vSF)

The policy term trains the student to match Stockfish's soft move distribution. The value term trains the student to match Stockfish's board evaluation, with λ controlling how much value accuracy matters relative to move prediction.

ℒ Total student training loss CE Cross-entropy policy loss
pSF Soft move probabilities from Stockfish MultiPV pS Student-predicted move probabilities
vS Student-predicted board value vSF Stockfish evaluation target
λ Weight on the value loss term MSE Mean squared error for board value
  • Soft policy target: Stockfish MultiPV gives several candidate moves with centipawn scores. We convert those scores with softmax, so the model learns that the best move is preferred but nearby alternatives can still be reasonable.
  • Student policy: the policy head outputs logits over possible moves. Cross-entropy penalizes the student when its move probabilities do not match the Stockfish-derived distribution.
  • Value target: the value head predicts a bounded version of Stockfish's centipawn evaluation, so the model learns whether the position is favorable or unfavorable, not only which move to play.
