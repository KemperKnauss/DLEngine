Compressing Chess Evaluation Networks for Edge-Device Inference

We train compact neural student models to imitate local Stockfish analysis, then compare how architecture size and depthwise separable convolutions affect the accuracy-efficiency tradeoff for low-memory chess evaluation.

University of Washington · CSE · Spring 2026
Motivation

Why Compress?

Strong chess analysis usually depends on expensive search and/or large learned evaluators. Stockfish can produce excellent move choices and centipawn evaluations, but running teacher-quality analysis for every position is too costly for lightweight or edge-device settings.

We investigate whether small neural students can preserve useful Stockfish-like behavior while reducing inference cost. The central question is which compact architecture gives the best tradeoff between imitation accuracy, parameter count, memory footprint, and CPU latency.

Data

Datasets & Preprocessing

Positions are sampled from the Lichess open database and labeled with a local Stockfish executable. The midpoint run uses a small subset to verify the complete pipeline before scaling.

  • PGN to FEN — games are expanded into individual board positions
  • Stockfish MultiPV — top candidate moves and centipawn evaluations become teacher labels
  • Tensor encoding — 18 channels encode pieces, side to move, castling rights, and en passant state

MultiPV centipawn scores are converted into soft policy targets so the student can learn that several moves may be reasonable, while the best evaluation is mapped to a bounded value target.

Methodology

Teacher-Student Pipeline

Stockfish is used as the teacher and a compact neural network is trained as the student. The student has a shared convolutional trunk, a policy head for move probabilities, and a value head for board evaluation.

StageTechniqueOutput
Data Convert Lichess PGN games into FEN positions Board states
Teacher Run Stockfish depth-limited MultiPV analysis Top moves + evals
Student Train small CNN and depthwise CNN variants Policy + value
Analysis Compare accuracy against inference cost Pareto frontier

The midpoint implementation has already completed this loop on a small sample. The final run will scale the number of positions, teacher depth, and training epochs.

Student Architecture

The Student replaces standard convolutions with depthwise separable convolutions to drastically reduce FLOPs while preserving representational capacity.

LayerTypeOutput
Input Board tensor C × 8 × 8
Conv Block ×N DW-Sep Conv F × 8 × 8
SE Squeeze-Excite Channel attention F × 8 × 8
Policy Head 1×1 Conv + FC Move logits
Value Head 1×1 Conv + FC Scalar eval

Student Training Loss

ℒ = α · MSE(ŷ, ySF) + (1−α) · KL( σ( zTτ ) ‖ σ( zSτ ) )

The policy term learns a soft distribution from Stockfish MultiPV scores, while the value term regresses the bounded Stockfish evaluation.

Planned Experiments

Related Works

Key Prior Work

1. Silver et al., "Mastering Chess and Shogi by Self-Play" (AlphaZero, 2018)
Demonstrated that policy/value neural networks can guide high-level chess play when combined with search. Our project uses a related policy/value framing, but studies small supervised students rather than self-play training.
2. Stockfish and NNUE Evaluation
Stockfish combines optimized search with a strong evaluation function and can run locally as a UCI engine. We use it as a reproducible teacher that generates best-move and centipawn labels for FEN positions.
3. Hinton et al. Distillation and MobileNet Efficient CNNs
Knowledge distillation motivates learning from a stronger teacher's softened outputs, while MobileNet-style depthwise separable convolutions motivate our lightweight architecture comparison for low-cost inference.
